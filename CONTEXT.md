# Steady Wins SEO Domain Context

## Glossary

### Package

A named SEO service offer with its own identity, category, price, copy, tagline, and delivery promise.

### Package page

The sales page for one Package. It presents the package proposition, supporting explanation, process, proof, offer, and a way to start a brief.

### Canonical package ID

The stable identity used to address a Package. Package routes derive from this ID; legacy route names are redirects, not alternate package identities.

### Package-specific tagline

Supporting microcopy belonging to a Package. It reinforces the primary CTA but does not replace the semantic sales proposition or H1.

### Representative package page

The 20 Day SEO Boost Package page used as the visual gate before a shared package-page treatment is propagated to the remaining packages.

### Conversational recommendation flow

A future progressive flow that begins with a website URL, provides useful guidance, and then gathers additional details to recommend a starting package or next step. It is currently parked and is not part of the package-page visual pass.
