# Local service website starter

This is a client-agnostic Astro starter for local service businesses. Replace
the placeholder data in `src/data/` before publishing.

## Safeguards

- A service area may have `slug: null` when it is served but does not have
  enough unique local evidence for a dedicated page.
- `npm run check:site` fails when a location guide and location record disagree.
- The starter contains no client claims, ratings, certifications, or prices.

## Commands

```sh
npm install
npm run check:site
npm run dev
npm run build
```
