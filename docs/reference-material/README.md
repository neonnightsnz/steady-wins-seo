# Reference material

These folders are source inputs used to build the Steady Wins showcase. They are kept out of the runtime tree so the production site remains easy to reuse.

- `Old-Draft-Steady-Wins/` — locked source copy and original page structure.
- `SEO-Business-Images/` — supplied colour/image references. The runtime copies used by the site live in `public/images/offers/`.
- `reference/` — visual reference capture used for the dark aesthetic and section rhythm.
- `new-client-site-template/` — reusable client-site framework and strategy references.
